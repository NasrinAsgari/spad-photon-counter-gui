# SPAD Photon Counter GUI

Real-time photon counting GUI for single-photon avalanche diode (SPAD) measurements using National Instruments DAQ hardware.

## Features
- Real-time photon counting
- Live time-trace visualization
- Real-time autocorrelation calculation
- NI-DAQ integration
- Continuous acquisition mode
- Binary data saving
- Automatic metadata logging

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python spad_photon_counter_gui.py
```
## Dependencies
- numpy
- matplotlib
- PyQt5
- nidaqmx

## Hardware
- National Instruments DAQ
- SPAD detector
- Counter/timing input
